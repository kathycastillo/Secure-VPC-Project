# Secure-VPC-Project
- AWS Hands-on project building a secure VPC with bastion host, private server, and controlled SSH access.

## Overview
This project demonstrates a secure VPC architecture in AWS, including:
- Public subnet with Public Admin Server
- Key-based SSH access
- Controlled network access via security groups

## How to Use / View
- Project documentation is in 'Project_Plan.md'
- Sreenshots and diagrams are in the 'images/' folder

## Key Features
- Secure network isolation
- Public sercer acting as a bastion host
- Private server inaccessible from the internet
